# Automated CI/CD Pipeline for ROS 2 TurtleBot3 Navigation

## Project Overview

This project demonstrates a CI pipeline for a custom ROS 2 TurtleBot3 navigation application using Github and Jenkins.

The application uses ROS 2 Humble and the Nav2 framework to send navigation goals to TurtleBot3.

## Technologies Used

-Ubuntu
-ROS 2 Humble
-TutleBot3
-Gazebo
-Nav2
-Python
-Git and GitHub
-Jenkins
-Docker
